# Canonical PDL Reference Works

This repository contains TEI XML editions of dictionaries, grammars,
commentaries, scholia, introductions, and other reference works distributed by
the Perseus Digital Library. The inventory below records work-level CTS
resources on the maintained development line. Individual XML versions are
identified by their current repository filenames.

Inventory status: 2026-10-08.

checked before redistribution.

## Validation

Run HookTest from the repository root. To validate the complete collection:

```console
hooktest ./ --scheme tei --workers 3 --verbose 10 --console table
```

To inspect one textgroup, add a filter such as:

```console
hooktest ./ --scheme tei --workers 1 --verbose 10 --console table --filter sec00009
```

## Installing in eXist-db

1. Install Apache Ant.
2. Run `ant` at the repository root to build the XAR package.
3. In the eXist-db package manager, upload and install the generated XAR file.
